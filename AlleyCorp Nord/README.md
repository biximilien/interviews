# AlleyCorp Nord Interview

I was given the choice between a coding challenge or completing a "Good First Issue" on an open source Project.
I chose the later and completed [https://github.com/solidusio/solidus/issues/4001](). 
I had chosen this project because I had built an e-commerce solution for a past employer using Solidus.
My PR [https://github.com/solidusio/solidus/pull/4158]() was accepted and merged.

In retrospect, that was a pretty bad idea as coding challenge as it gave us little to no talking point for the subsequent interview. So I would advise against it.
